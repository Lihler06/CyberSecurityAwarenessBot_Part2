# Cybersecurity Awareness Chatbot (WPF)

## Description
This project is a WPF-based Cybersecurity Awareness Chatbot developed for academic purposes. It educates users about online safety topics such as phishing, passwords, privacy, scams, and malware.

## Features
- WPF Graphical User Interface
- Keyword recognition system
- Randomised chatbot responses
- Memory system for user preferences
- Sentiment detection (emotional response handling)
- Delegate-based architecture
- Audio greeting on startup
- Interactive conversational flow

## How to Run
1. Open solution in Visual Studio
2. Ensure `Greeting.wav` is included in project
3. Set startup project to WPF application
4. Run using F5
